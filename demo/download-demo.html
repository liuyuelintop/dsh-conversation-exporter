Local download mechanism (standalone demo)

This page proves the browser-side half of the exporter path: take Markdown text produced by the pipeline, wrap it in a Blob, create an object URL, click a temporary <a download>, then revoke the URL. No server, no upload, nothing leaves this machine.

A DSH Web plugin would do exactly this inside the slot conversation.session.header.utilities (the same seat as the official “Session log” button). In-page activation requires plugin approval, which is disabled in the unattended spike session — hence this standalone proof.
